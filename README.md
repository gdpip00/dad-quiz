# 初当爸 · 育儿知识题库

[v0.2.1 正式版](v0.2.1.json)收录 690 道情景单选，涵盖孕期、婴儿及产后照护。题目与解析含 AI 辅助编写内容。逐题审核进度见各题的 `reviewStatus`。

首批 10 道 ABCD 情景单选，涵盖孕期照护、婴儿照护和产后照护。题目、答案、逐项解析和原始资料链接见 [v0.1.0.json](v0.1.0.json)。

- `topic` 是一级分类，取值为 `pregnancy`、`baby`、`postpartum`。
- `stage` 是给读者看的适用阶段。 `tags` 是可多选的知识点标签。
- `focus` 说明这道题考什么。 `sources` 提供核对依据。
- `id` 是稳定题号。改题时沿用 ID 并增加 `revision`。题库每次发布使用独立版本。

题目用于学习。涉及就医或用药时，解析以所列资料为依据，实际处理需结合当地医疗建议。

本地校验命令

```sh
node validate.js v0.1.0.json
```

## 社区审题草稿

[v0.2.0 草稿](drafts/v0.2.0.json)收录 690 道情景题，供核对答案、来源与重复考点。题库中的 `human-review` 表示待人工复核，`revise` 表示已有待修改项。部分题目还需补充来源。小程序正式题库只同步标记为 `published` 的版本。
